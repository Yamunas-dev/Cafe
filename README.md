# The Green Cafe — React + Vite

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (normally http://localhost:5173/).

## Build for production

```bash
npm run build
npm run preview
```

The project includes the updated menu, search, Add to Order/cart, favorites, customer reviews, responsive layout, and WhatsApp ordering flow from the supplied source files.
